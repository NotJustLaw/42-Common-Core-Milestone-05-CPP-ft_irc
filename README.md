IRC is not safe due to:
- Plain-text messaging - An Internet Service Provider or a middle-man can read the connection's traffic;
- No encryption - Server administrators and other operators can read your messages;
- IP address exposure - IRC servers can (and will) expose your IP address to other connected individuals;
- Trust based file transfer - Transferring files sent by other connected clients can contain malware.
